A browser-and-mobile-playable pipe puzzle game inspired by Pipe Mania / Pipe Dream. The player taps tiles on a grid to rotate them 90 degrees clockwise, connecting a Source to a Sink with a continuous flow path. Tiles fill with color as they connect. Features include straight, corner, T-junction, and cross tiles, plus advanced bridge/tunnel and portal/teleport mechanics. Progressive difficulty from small easy grids to expert levels with all mechanics combined. Should work on mobile (touch) and web (click). Built with Flutter/Dart for cross-platform support.
